# Contributing to NocturneDecomp

This is a personal project, maintained in spare time. Issues and pull requests are welcome, and are
looked at when there is time to, but there is no promise that a change will be accepted or a
request answered.

Please follow the [Code of Conduct](CODE_OF_CONDUCT.md).

## Reporting a bug or asking for a feature

Open an [issue](https://github.com/NearlyTRex/NocturneDecomp/issues/new/choose) and pick the form that fits. The
forms ask for what is needed to understand the problem, so filling them in fully saves a round of
questions.

Security problems are the exception: report them privately, as the
[Security Policy](SECURITY.md) explains, rather than in an issue.

## Proposing a change

For anything bigger than a small fix, open an issue first, so the idea can be discussed before you
spend time on it.

1. Fork the repository and make your change on a branch.
2. Keep it to one change, with tests for new behavior where the project has tests.
3. Make sure the checks pass locally where you can; CI runs them again on the pull request.
4. Open a pull request and fill in its template.

By contributing, you agree that your contribution is licensed under the repository's
[license](https://github.com/NearlyTRex/NocturneDecomp/blob/HEAD/LICENSE).
