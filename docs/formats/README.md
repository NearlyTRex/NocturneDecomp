# File formats

The formats of the files the engine reads, as the C++ recreation reads them, one document each.
Each names the code it is taken from, gives every field with the versions that hold it, and marks
what the recreation adds to the original's format.

| Format | Files | Document |
|---|---|---|
| Set | `models\*.SET`: a set's geometry, fog, water, sky, lights, cameras, rooms, virtual director boxes, visibility lists, and the recreation's own blocks | [set.md](set.md) |
