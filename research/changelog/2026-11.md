# Changelog: November 2026

## 2026-11-17
- **Python tooling coverage: 26 more files at 100%**, and the omit list is down from 88 to 54.
  Eight spent one-offs were deleted instead: the tridx7 CRT/APIDLL appliers (`apply_crt_signatures`,
  `apply_apidll_signatures`, `name_crt_functions`), `fix_movsd_caves`,
  `generate_esp_to_ebp_patches`, `cleanup_unused_locals`, `strip_unused_locals` and
  `analyze_crt_functions`. Bugs the tests found:
  - `disassemble_function.py` dropped the last byte of every range, usually the `RET`: Ghidra's
    range ends are inclusive. An address also matched any file name containing its digits.
  - The render-flags transform rewrote `g_RenderStateFlags.bytes[N] | k` and `^ k` as dword
    expressions, which pull in the other three bytes; and `bytes[1..3] & k` lost its shift. Only
    `&` with a byte-wide mask is rewritten now, shifted back for bytes 1-3 unless the result is only
    compared with 0, where the shift changes nothing. It also names the
    literal in `g_RenderStateFlags.dword = g_INT_x | 0x205` (six sites in the BW builds).
  - The export's JSON caches dropped an unreadable per-function or `callfixups.json` file without a
    word, after which cleanup deleted it. They warn now, and a failed `callfixups.json` write stops
    the export.
  - `adjacency_sentinel_rewrites.md` and `shim_compilation.txt` could go stale or reorder: an
    export with no rewrites left the old report behind, and shim failures were listed in
    completion order.
  - `netplay_trace_diff.py` kept only the last damage/burn line of a frame, and crashed on an
    empty RNG trace.
  - `repair_broken_signatures.py` and `add_runtime_heap_block.py` mutated the project without a
    snapshot; both take one before applying now.
  - The decompiled-signature reader treated the line above a one-line `/* */` comment as comment.
  - `struct_quality.txt` counted `padding_size`, `padded_width` and `padded_height` as padding
    and missed Ghidra's `field_0x4` default name (bw1). Its search for `pseudocode/` above the
    source folder never ended when there was none.

- **`infer_globals.py` plans the globals a program has not defined**: start, type, element count
  and an automatic `g_<type>_<address>` name. It reads the PE's base relocations, so every
  address operand is seen, including `MOV reg,imm32` loads Ghidra makes no reference for. It types
  from FPU/MOVSX/MOVZX access widths, from dereferences, from the prototype of the function an
  address is passed to, from relocated pointer tables, and from nocedit through the sibling
  mapping. A build's own access wins over nocedit's type: bw1 keeps `-π/4` as a `float` where
  nocedit has a `double`. Folded offsets (`arr[i-1]` as `[reg*4 + arr-4]`) are clustered onto
  one array. A string that code writes into, or passes as a destination, is a `char[N]` buffer,
  not a literal. The plan never overlaps itself or a kept definition, and the default `--apply`
  dry run checks every row against the live program.

  nocedit's signature.

- **123 more BW names** (bw1 33, bw2 48, bw3 42), each source gated on the class that owns the

  Two of those, and bw2's six mid-instruction entries, were not functions: they were aligned
  branch targets inside the function before. The sign is that the only reference to the corrected
