## Proposed Structure:

Since vertices start at +0x14 (20 bytes), and we know:
- +0x00: type (int)
- +0x04: size (int)
- +0x08: child_count (int) - must be 2
- +0x0C: ??? (int) - unknown purpose
- +0x10: vertex_count (int)
- +0x14: vertices[] (CVector3i array)

We should define it as:

```c
// Keyframe data header (20 bytes)
typedef struct SMRGLKeyframeHeader {
    int type;         // 0x00 - MRGL type identifier
    int size;         // 0x04 - Total size in bytes
    int child_count;  // 0x08 - Number of child blocks (always 2 for keyframes?)
    int unknown_0C;   // 0x0C - Purpose unknown
    int vertex_count; // 0x10 - Number of vertices in this keyframe
} SMRGLKeyframeHeader; // 20 bytes (0x14)

// Keyframe vertex data entry
typedef struct SMRGLKeyframeVertexData {
    SMRGLKeyframeHeader header; // 0x00
    CVector3i vertices[1];      // 0x14 - Actually variable length based on vertex_count
} SMRGLKeyframeVertexData;
```

Better approach following primitive pattern:
```c
typedef struct SMRGLKeyframeData {
    SMRGLKeyframeHeader header; // 0x00 (20 bytes)
    CVector3i vertex;           // 0x14 (12 bytes) - single vertex entry
} SMRGLKeyframeData; // 32 bytes per vertex entry

// To access multiple vertices, cast to SMRGLKeyframeHeader* and use:
// CVector3i* vertices = (CVector3i*)((char*)header + 0x14);
```

## SMRGLKeyframeModel Structure

Current definition appears correct:
```c
typedef struct SMRGLKeyframeModel {
    int type;                    // 0x00
    int size;                    // 0x04
    int keyframe_count;          // 0x08
    int cycle_length;            // 0x0C
    int current_position;        // 0x10
    SMRGLKeyframe* base_keyframes; // 0x14
    char filenames[16][16];      // 0x18 (256 bytes)
    SMRGLKeyframe* loaded_frames[16]; // 0x118 (64 bytes)
} SMRGLKeyframeModel; // 344 bytes (0x158)
```

This matches the assembly accesses:
- +0x08: keyframe_count ✓
- +0x14: base_keyframes pointer ✓
- +0x18: filenames array ✓
- +0x118: loaded_frames array ✓
